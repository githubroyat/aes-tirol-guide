# AES Tirol Subject Guide

An unofficial guide for pupils at AES Tirol choosing their S6–S7 subjects for the European Baccalaureate, and what each choice means for university in Austria and abroad.

The whole site is one file, `index.html`. Download it and open it in a browser to view it.

Unofficial: not published by AES Tirol, the European Schools or any university. It may contain errors or be out of date; always check the official sources linked on each page.
